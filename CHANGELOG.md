# Changelog

All notable changes to this project are documented in this file.

The project follows [Semantic Versioning](https://semver.org/). Releases in the
`0.x` series represent initial development and may contain documented API
changes.

## 0.1.0 - 2026-07-29

### Added

- Protobuf Web Token encoding and parsing with typed claims.
- HS256, RS256, and EdDSA signing and verification.
- Standard time-based claim validation.
- Protocol Buffer payload support for custom claims.
- Initial crates.io and GitHub release automation.
