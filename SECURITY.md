# Security Policy

## Supported versions

During initial development, security fixes are applied to the latest `0.x`
release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
security advisory flow for this repository:

<https://github.com/mobinova/pwt-rust/security/advisories/new>

Include reproduction steps, affected versions, and potential impact. We will
acknowledge a complete report as soon as practical and coordinate disclosure
with the reporter.
